# Solar H2 Mobility

태양광 패널과 수소차의 에너지 흐름을 함께 관리하는 인터랙티브 웹 데모입니다.

## 구조

- `index.html` — 화면별 템플릿과 애플리케이션 셸
- `styles.css` — 반응형 UI, 차트/게이지/상태 컴포넌트 스타일
- `app.js` — 가상 센서 상태, 화면 렌더링, 알림·세척·기간 선택 상호작용

## 데이터 설계

`app.js`의 `state`는 추후 센서 또는 차량 API 어댑터로 대체할 수 있는 단일 상태 모델입니다. 패널 세척을 완료하면 오염도와 발전 효율이 함께 바뀌고, 관련 알림이 생성됩니다.

## 실행

정적 파일을 지원하는 서버에서 프로젝트 루트를 열면 됩니다. 예: `npx serve . -l 4173`
